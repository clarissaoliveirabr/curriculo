## Como usar esta lista

1. **Escolha o cargo-alvo da vaga específica.**
2. Abra a descrição da vaga e copie os termos exatos usados nela (sinônimos
   importam para o ATS: "gestão de produtos" ≠ "product management" para
   alguns parsers).
3. Insira esses termos no bloco **PALAVRAS-CHAVE / COMPETÊNCIAS** e no
   **RESUMO PROFISSIONAL** do currículo mestre — o ATS pontua presença literal
   do termo, não sinônimo.
4. Reordene os 3–4 bullets mais relevantes de cada experiência para o topo.
